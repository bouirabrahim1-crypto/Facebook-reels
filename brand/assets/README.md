# أصول الهوية البصرية — SKAMS YAMS

**الشعار والعلامة المائية معتمدان ✓** (التصميم تمت الموافقة عليه). هذا المجلد هو المرجع الوحيد لها — لا تُعاد إضافتها أو تعديلها دون موافقة صريحة جديدة.

## الملفات

| الملف | الوصف |
|---|---|
| `sy-monogram.svg` | الرمز المختصر SY، مربع (400×400)، بخلفية كحلية، لاستعماله كأيقونة أو صورة ملف شخصي. |
| `sy-logo-full.svg` | الشعار الكامل: الرمز + اسم SKAMS YAMS بالحروف اللاتينية + العبارة الرسمية. مناسب للافتتاحية والمواد التعريفية. |
| `sy-watermark.svg` | نسخة العلامة المائية (متجهة): فضية، خلفية شفافة، شفافية 55%، للاستعمال فوق لقطات الفيديو. |
| `sy-watermark.png` | **النسخة الجاهزة للاستعمال فعلياً فوق الفيديو** (raster، شفافية مدمجة)، تُستعمل مباشرة مع ffmpeg — انظر `brand/templates/APPLY_BRANDING.md`. |

## ملاحظات تصميمية

- حرف **S** بالذهبي (`#C9A54C` → `#E6C77A`)، حرف **Y** بالفضي (`#C0C7D1` → `#E8ECF1`)، متداخلان مع إطار دائري رقيق يوحي بعدسة الكاميرا.
- الخط المستعمل للحروف اللاتينية هو Montserrat Bold، ولخط العناوين العربية Cairo.
- ملفات الـ SVG متجهة، قابلة لإعادة التلوين والتحجيم دون فقدان الجودة.

## الاستعمال الإلزامي

**كل فيديو ومشروع من SKAMS YAMS** يجب أن يحمل `sy-watermark.png` طوال مدته (ما عدا مشاهد الافتتاحية/الخاتمة الكاملة)، وينتهي بخاتمة `templates/outro/outro.mp4`. التفاصيل والأوامر الجاهزة في `brand/templates/APPLY_BRANDING.md`.
