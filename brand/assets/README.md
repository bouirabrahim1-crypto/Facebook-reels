# أصول الهوية البصرية — SKAMS YAMS

هذا المجلد يحتوي على الأصول البصرية الأساسية للعلامة. **كل الملفات هنا مسودات أولى (drafts) لم تُعتمد بعد**، أنشئت كتفسير بصري أول لوصف الهوية، وتحتاج موافقتك قبل اعتمادها النهائي أو استعمالها في فيديو منشور.

## الملفات

| الملف | الوصف |
|---|---|
| `sy-monogram.svg` | الرمز المختصر SY، مربع (400×400)، بخلفية كحلية، لاستعماله كأيقونة أو صورة ملف شخصي. |
| `sy-logo-full.svg` | الشعار الكامل: الرمز + اسم SKAMS YAMS بالحروف اللاتينية + العبارة الرسمية. مناسب للافتتاحية والمواد التعريفية. |
| `sy-watermark.svg` | نسخة العلامة المائية: فضية، خلفية شفافة، شفافية 55%، للاستعمال فوق لقطات الفيديو. |

## ملاحظات تصميمية

- حرف **S** بالذهبي (`#C9A54C` → `#E6C77A`)، حرف **Y** بالفضي (`#C0C7D1` → `#E8ECF1`)، متداخلان مع إطار دائري رقيق يوحي بعدسة الكاميرا.
- الخط المستعمل حالياً للحروف اللاتينية هو Montserrat Bold كبديل مؤقت، ولخط العناوين العربية Cairo.
- هذه ملفات SVG متجهة (vector)، قابلة لإعادة التلوين والتحجيم دون فقدان الجودة، ويمكن تصديرها إلى PNG بأي مقاس عند الحاجة.

## ما ينتظر الموافقة

- شكل التداخل الهندسي بين S و Y (حالياً تجاور بسيط بشفافية؛ الوصف الأصلي يقترح تداخلاً هندسياً أعمق — يحتاج تكرار تصميم إذا رفضت هذا الاتجاه).
- اختيار Montserrat Bold كخط نهائي للرمز (قابل للتغيير).
