# دخلة العلامة الموحدة (Intro) — SKAMS YAMS

**معتمدة ✓** — تُلحق فبداية كل فيديو، قبل مشهد الخطاف.

- `intro_frame.png` — الإطار الثابت (1080×1920): الصورة الأصلية `brand/assets/sy-intro-source.png` كاملة بدون أي قص (العبارة الرسمية بأكملها ظاهرة)، مُلصقة على خلفية فضائية (نجوم) مُولَّدة برمجياً (`build_frame.py`) تمتد لتعمر الإطار بالكامل — بلا حواف سوداء مسطحة وبلا قص فالنص.
- `render/build_frame.py` — يُعيد توليد `intro_frame.png` (خلفية النجوم + لصق الصورة الكاملة بالمنتصف).
- `intro.mp4` — الفيديو النهائي المعتمد (3 ثوانٍ، 1080×1920، بدون صوت): ظهور تدريجي (fade-in) من 0.1s إلى 0.6s، ثبات، ثم اختفاء تدريجي (fade-out) من 2.5s إلى 3.0s.
- `render/` — المصدر الكامل لإعادة التوليد عند أي تعديل (`intro.html` + `render.js`)، بنفس نمط `templates/outro/render/`.

## الاستعمال

تُلحق فبداية كل فيديو جديد (قبل مشهد `hook`)، بنفس طريقة إلحاق الخاتمة فالنهاية — انظر `brand/templates/APPLY_BRANDING.md`.

## لإعادة التوليد بعد أي تعديل

```sh
cd templates/intro/render
python3 build_frame.py   # فقط إذا تغيّرت الصورة الأصلية أو أسلوب التركيب
node render.js
```

لا يُستبدل `intro.mp4` المعتمد دون موافقة صريحة.
