# قالب الصورة المصغرة

`thumbnail_template.svg` قالب جاهز للتخصيص لكل فيديو جديد.

## خطوات الاستعمال

1. انسخ الملف إلى مجلد مشروع الفيديو الجديد (`templates/video-project`).
2. عوّض `{{TITLE_LINE_1}}` و`{{TITLE_LINE_2}}` بعنوان عربي قصير وقوي يعبّر عن الفيديو.
3. استبدل خلفية `{{VISUAL_PLACEHOLDER}}` بصورة أو لقطة حقيقية ذات علاقة مباشرة بالموضوع (لا صور عامة).
4. صدّر النتيجة إلى PNG/JPG بالمقاس النهائي، واعرضها للمراجعة قبل الاعتماد — لا تُنشر صورة مصغرة دون موافقة.

## قواعد ثابتة (من دليل الهوية)

- عنوان عربي قصير وواضح حتى على شاشة الهاتف.
- تباين قوي بين النص والخلفية.
- رمز SY يظهر بتوازن، دون أن يطغى على الصورة.
- بدون حشو بالتفاصيل والنصوص الزائدة.
