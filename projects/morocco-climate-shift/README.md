# مشروع فيديو — علاش بدا طقس المغرب كيتبدل؟

الحالة: السكريبت والمصادر جاهزون، بانتظار موافقتك قبل التسجيل الصوتي (انظر `factcheck.md`).

## محتوى القالب

| العنصر | الدور |
|---|---|
| `script.md` | هيكل السكريبت (خطاف، تقديم، سياق، وقائع، تحليل، خاتمة) |
| `sources.md` | قائمة المصادر والروابط وتاريخ الاطلاع عليها |
| `factcheck.md` | قائمة التحقق من الوقائع قبل التسجيل الصوتي |
| `episode.json` | ملف المشروع لخط أنابيب الرندر المحلي (`app/services/video_project`، انظر `docs/video-projects.md`) |
| `assets/footage/` | اللقطات والفيديوهات الخام |
| `assets/voiceover/` | ملفات التعليق الصوتي |
| `assets/subtitles/` | ملفات الترجمة/الترجمة المتزامنة |
| `assets/graphics/` | الرسومات والخرائط وبطاقات البيانات الخاصة بهذا الفيديو |
| `assets/renders/` | المخرجات النهائية والمعاينات |

## خطوات العمل المرجعية

اتبع `workflow/VIDEO_WORKFLOW.md` من جذر المشروع للمراحل الكاملة من الفكرة إلى النشر، و`workflow/FACT_CHECK.md` لقواعد التحقق، و`workflow/PUBLISHING.md` قبل أي نشر.

## تذكير

- لا تبدأ التسجيل الصوتي النهائي أو الرندر النهائي دون موافقة صريحة.
- اعرض معاينة الصورة المصغرة (من `templates/thumbnail/`) والخاتمة قبل الاعتماد.
- احتفظ بنسخة أصلية من كل الأصول قبل أي تعديل كبير.
